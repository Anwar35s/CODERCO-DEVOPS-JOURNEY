- **Searching and composing commands:** search text, sort results, find unique lines, and pass output between commands with pipes.
- **Text and encoded data:** recognize the difference between readable text and binary data, and practice decoding common text representations.
- **Archives and compression:** identify common archive and compression formats, then choose the appropriate tool.
- **Safer troubleshooting:** work in temporary directories, inspect files before acting, read command help, and treat errors as clues.
