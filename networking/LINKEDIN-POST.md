🌐 **Networking Fundamentals: complete!**

I’ve finished my networking fundamentals assignment by connecting the concepts to a live deployment:

- Registered **anwarali.co.uk** with Cloudflare
- Launched an Ubuntu server on AWS EC2
- Installed NGINX and served its welcome page
- Created a DNS A record pointing my domain to the EC2 public IPv4 address
- Verified the DNS answer with `dig +short anwarali.co.uk`

Along the way, I learned how DNS, IP addresses, ports, routing, and firewall rules work together to get a web request from a browser to a server.

The site is live over HTTP: http://anwarali.co.uk
